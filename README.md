# Library Management System

## Overview
A Java console-based Library Management System built using Java, JDBC and MySQL.

## Features

### Book Management
✓ Add Book
✓ View Books
✓ Update Book
✓ Delete Book

### Member Management
✓ Add Member
✓ View Members
✓ Update Member
✓ Delete Member

## Technologies Used

Java 21
JDBC
MySQL
Maven

## Project Structure

src/main/java

 └── com.kaarthi.library

      ├── config
      ├── dao
      ├── model
      ├── service
      └── main


## Database Setup

Create database:

library_management_system


Tables:

book

member

admin

issue_record


## How to Run

1. Clone repository

2. Configure MySQL credentials

3. Run Maven project

4. Start LibraryManagementSystem.java
